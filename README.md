## Instalación en el celular (PWA)

### Android (Chrome)
1. Abre el link en **Google Chrome**.
2. Toca el menú **⋮** (arriba a la derecha).
3. Selecciona **Add to home screen** y luego **Install**.
4. Sigue las instrucciones en pantalla.

### iPhone (Safari)
1. Abre el link en **Safari**.
2. Toca **Share** (Compartir).
3. Baja y selecciona **Add to Home Screen**.
4. Confirma con **Add**.
